# Org Explorer

Install Microsoft Authentication and connect it using the shared Teams web sign-in. Add a Org Explorer connection, choose **Use Microsoft Authentication**, and select the same source used by the other Microsoft services. You can also select a source explicitly shared by a direct peer. Existing credentials renew over HTTP while the authentication device is offline.

This connection is read-only. Search people, inspect profiles and browse managers, peers, direct reports and bounded subtrees. Unavailable profile fields are omitted. No new admin consent is requested.

See the API reference for request schemas and examples. Full limits and operation details are in the Microsoft helper documentation: [Office content adapter](https://github.com/tader/switchboard-plugin-microsoft/blob/main/plugins/microsoft/content/README.md).
